TerranSoul and Memo // current state

The brain, as built in November 2026

As of November 2026 · TerranSoulApp 73653ff0 (5 Nov) · Memo 78d1b122 (5 Nov) · TerranSoulMemory ec0fb10 (12 Oct)

The map above shows the idea: a language model wrapped in the regions of a brain. This section says what is actually built today, what is built but switched off, and what is still only planned. Where a number appears, it comes from a dated benchmark run in the repositories.

What is true today

  • There are two editions of one brain. TerranSoul runs on your own computer. Memo is the hosted, multi-tenant version at memo.terranimus.com, built to give a company's agents the same brain.
  • Search ranks memories by merging several ranked lists with a method called Reciprocal Rank Fusion (RRF, k=60). A plain merge of vector and keyword search is what wins in our measurements.
  • The knowledge graph is switched off in ranking by default. Measured with real links present, it made results worse, not better.
  • Memo's results matched TerranSoul's on all 1,982 LoCoMo-10 questions when last compared on 22 Oct 2026. That comparison has not been re-run since TerranSoul moved on.
  • Memory in both editions is stored as text only. On the desktop, scanned images and PDFs are first turned into text (OCR and a vision model); no image, audio or screen is kept as such.

RRF: each search method ranks the memories; a memory near the top of several lists rises to the top of the merged list. k=60 is a smoothing constant so no single method dominates.

R@10 (recall) is the share of questions whose right memory is in the top 10 results; NDCG@10 scores how high the right memory sits in the top 10. LoCoMo-10 and LongMemEval-S are public benchmarks of long conversations with questions about them.

Two editions of one brain

Since 22 Oct 2026, Memo is TerranSoul's cloud version and is kept in step with it. A third piece, TerranSoulMemory, is the lite brain that web apps copy into themselves.

TerranSoul (desktop)

Runs locally with SQLite. Embeddings come from Ollama (embeddinggemma, 768 dimensions) and keyword candidates come from SQLite FTS5 (BM25 only orders that candidate pool). Vector search uses an approximate index (usearch HNSW). The default model provider since 30–31 Oct 2026 is a logged-in local Claude account, otherwise Ollama with a gemma4 model. There are 8 provider backends in all.

Memo (hosted)

Runs on MariaDB 11.4 with one company per tenant and a paired test company for each. Embeddings are OpenAI text-embedding-3-small (1536 dimensions). Keyword candidates come from plain text matching (no FTS5), then the same weighted keyword score as desktop (not BM25). Vector ranking is exact cosine over at most 1,000 candidates, with no approximate index.

Naming note: the research paper this site links to uses the lowercase word "memo" for retrieve-and-paste memory, in its "memo versus memory" argument. The product Memo here is a different thing.

Layers and data model

  1. Model core. Any language model. TerranSoul has 8 backends: free API, paid API, Ollama, LM Studio, llama.cpp, Colibri, vLLM and Claude CLI. A paid API is never chosen by default. Memo uses hosted models (OpenAI by default, with a DeepSeek fallback) and no local model.
  2. Memory rows. Every memory has a tier (short, working, long), a type (fact, preference, context, summary), a cognitive kind (episodic, semantic, procedural, judgment, negative) and a source kind. The desktop schema is at version 71.
  3. Graph. Typed links between memories (such as supersedes and contradicts) with a start and an end date. A link is closed, not deleted. There is one clock (valid from, valid to).
  4. Outcome ledger. Since September 2026 a memory that has been graded carries its outcome (one never graded carries none). A memory that failed twice in a row with no success since is marked refuted and its body is withheld. Outcome nudges ranking only slightly (a 15% multiplier); an open conflict demotes both sides more strongly (x0.7).
  5. Doors in. MCP tools, plus gRPC (brain.v1 and phone_control.v1). The MCP list shows exactly 12 brain tools: brain_search, brain_get_entry, brain_kg_neighbors, brain_ingest_lesson, brain_ingest_url, brain_append, brain_add_edge, brain_close_edge, brain_delete_memory, brain_observe_outcome, brain_verify_completion and brain_health. A further 56 brain_* tools exist in the code and can be called by name, but are not listed. The non-brain tools (code, web search, email, channels, observability) stay on the list; the three canvas tools appear only when a canvas host is connected.

The phone contract is gRPC (PhoneControl), not MCP. Native mobile apps are not shipped. What exists is a paired web client whose remote chat already used gRPC-Web; on 4 Nov 2026 it gained a Watch tab, which lets a paired viewer watch the desktop (off until the owner switches it on).

Retrieval pipeline

Desktop chat, the command line and MCP search share one retrieval core. In order:

  1. Candidate channels. A dense vector channel, a keyword channel (a term-weighted match score in both editions, not Okapi BM25: a hit in a tag counts most, then a word in the text, then any substring, and rarer words weigh more; desktop uses FTS5/BM25 only to gather its candidates), and a trigram channel (ranked with BM25) used only for Chinese, Japanese and Korean text. A community-summary channel exists but is off by default.
  2. Merge with RRF, k=60. Only these channels vote.
  3. Small multipliers after the merge. Graph and activation together are limited to half a rank. Freshness moves a score by about 3%. Outcome applies the 15% multiplier above. A memory on either side of an open conflict is also scaled by 0.7, outside the half-rank limit. These adjust the order; they are not extra voters.
  4. Optional rerank. An AI-judge rerank exists. It is off for chat and think, and off on the default local path. Measured, it took 4 to 19 seconds against well under a second without it, and could return nothing. Memo has no rerank wired.
  5. Eligibility gate (desktop streaming only). The default desktop chat path uses a separate retriever with a 0.30 cut-off on a weighted score, then keeps the top 8. Without an embedding of the question it is keyword only, and no benchmark measures this path yet.

Thinking modes

There are six: Auto (default), Chat, Think, Research, Max and SelfRag (desktop only, local Ollama). MCP does not accept Auto. Chat is plain merged recall. Since 1 Sep 2026 Think follows no graph links, so it is almost the same as Chat: in Memo's harness only 8 of 1,982 result lists differ.

Latest LongMemEval-S (500 questions, retrieval only): chat, 30 Aug 2026, R@5 99.2, NDCG@10 94.0, 203 ms. Plain RRF, 22 Aug 2026, NDCG@10 94.9. Think, research and max have not been re-measured since the graph change. This measures finding the right memory, not the accuracy of an answer.

Link expansion has been off by default since 1 Sep 2026. A cause is in the code: a link's confidence is shared entities divided by the source memory's own entity count, so short memories win the limited link budget. Memo repeated the test on LoCoMo-10 on 22 Oct 2026 using TerranSoul's own code: links alone did not change the lists, link expansion fell from about 69 to 65.6 on R@10, and a PageRank variant lowered NDCG@10 from 45.2 to 39.6.

Memo now adds links of its own at write time (5 Nov 2026): from stored-vector similarity and from shared tags, with no model call. These links show on the map and in neighbour queries but are held out of ranking until a benchmark line releases them.

On vectors, the desktop index once held 0 vectors against 1,351 embedded rows (found and fixed 16 Aug 2026), so a silent index failure is a known risk. The seeded index tuning settings are not read by production code, and two vector-compression modules (RaBitQ, MUVERA) have no production caller.

Memo's two modes

MCP mode

The brain_* tools at POST /mcp, REST /v1/search and gRPC Brain. It always ranks like TerranSoul's Think and takes no mode argument. Sign-in is OAuth 2.1. Memo is listed in the MCP Registry as com.terranimus/memo (version 0.1.1, 3 Nov 2026).

Streaming mode

Chat at /v1/chat and /v1/chat/stream, /v1/answer, AG-UI and gRPC PhoneControl. It takes auto, chat, think, research or max, with auto the default. Research and max are built but off and unbenchmarked.

Memo serves TerranSoul's own protocol files and tool schemas, over gRPC-Web and Connect because the host speaks HTTP/1.1. On 22 Oct 2026, MCP mode returned the same top 20 and streaming mode the same top 8 as TerranSoul on all 1,982 LoCoMo-10 questions. On the 1,536 scored questions, Memo (R@10 69.1, NDCG@10 45.2, the same as TerranSoul's MCP path; the committed scoreboard still shows 68.9 and is stale) beat every Neo4j retriever tested (best R@10 61.8), but answers in about 18–20 ms against Neo4j's 2–4.5 ms. The benchmark used a small English embedder, not Memo's production one.

Parity drift: TerranSoul has moved on since 22 Oct (118 commits, and a changed phone protocol file on 4 Nov). The record of minimum scores to hold was copied from earlier runs, not re-measured.

What Memo adds, and what it lacks

Adds

  • Tenants, namespaces and a paired test company per company.
  • Approvals, an audit log, spend ceilings, and sign-in through Terranimus Identity.
  • A secret scrub on every write, and a check that refuses near-duplicate writes by meaning.
  • Channels: Messenger, Zalo, Discord and a website widget.
  • Minimum benchmark scores, checked on questions kept out of tuning, so a ranking change must show a measured win first.

Lacks (against TerranSoul)

  • No approximate vector index, no FTS5 candidate search, no HyDE, no rerank.
  • No decay, access counting or garbage collection, by design.
  • No code tools and no local models.
  • No LongMemEval number yet.

Limits to know

  • Every LongMemEval number measures retrieval with embeddings on. The default desktop chat path can run keyword-only, so those numbers do not describe it.
  • The ranking floor (NDCG@10 95.1) is not regained: current plain-RRF is 94.9 and whether to accept that is still undecided.
  • Scale beyond 1 million rows is untested on desktop. Memo's exact-cosine search is limited to 1,000 candidates per query.
  • On 26–27 Oct 2026 one store lock stalled recall (a short search took 38.5 s on the old build, measured on the morning of 27 Oct). After fixes the same search took 0.5 s once, but that run is confounded (the embedding service had been swapped for an empty one, so a fallback embedder ran). The single lock remains.
  • Vendor accuracy figures from other memory products are self-reported on different setups and are not comparable with our recall numbers.
